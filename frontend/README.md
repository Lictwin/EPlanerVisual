# EPlaner Visual (Frontend)

Визуальный редактор алгоритмов и диаграмм для системы EPlaner.

## Стек технологий
- React + TypeScript
- Vite (сборщик)
- React Flow (библиотека холста)
- Zustand (стейт-менеджер)

## Как запустить проект локально
1. Откройте терминал и перейдите в папку проекта:
   cd frontend
2. Установите зависимости:
   npm install
3. Запустите сервер разработки:
   npm run dev
4. Перейдите в браузере по адресу: http://localhost:5173/

## Структура папок (src)
- /canvas — логика холста, узлы и связи (React Flow)
- /components — UI-компоненты (панели, кнопки, инспектор)

## Правила работы с Git
1. Работаем только через Pull Requests. В ветку `main` пушить напрямую ЗАПРЕЩЕНО.
2. Создаем ветку под свою задачу: `git checkout -b feature/название-задачи`
3. Делаем коммиты: `git commit -m "feat: что сделано"`
4. Пушим: `git push origin feature/название-задачи`
5. На GitHub нажимаем "Compare & pull request". Ждем ревью.
